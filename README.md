# Brazilian E-Commerce SQL Analysis

## Project Overview

This project focuses on analyzing a real-world Brazilian e-commerce dataset using SQL to extract meaningful business insights related to sales performance, customer behavior, product trends, delivery performance, and customer satisfaction.

The dataset contains multiple related tables such as customers, orders, payments, products, reviews, and sellers, making it ideal for practicing real-world SQL analysis.

---

## Objectives

* Analyze overall sales and revenue trends
* Identify top-performing product categories
* Find high-value customers and purchase patterns
* Analyze delivery performance and delays
* Evaluate customer reviews and ratings

---
